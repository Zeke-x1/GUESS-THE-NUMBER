# Guess The Number Game

A minimalist web-based number guessing game built with Python (Flask), HTML, CSS, and JavaScript

## Features
- Range: 1 to 100
- Dark minimalist aesthetic without emojis
- Atmospheric background animations (slow drifting glow, subtle floating particles)
- Visual feedback animations (shake on incorrect guesses, pulses, celebratory transitions on victory)
- Attempt tracking and guess history tags
