# Darkness Guess The Number Game

A minimalist web-based number guessing game built with Python (Flask), HTML5, CSS3, and JavaScript.

## Features
- Range: 1 to 100
- Dark minimalist aesthetic without emojis
- Atmospheric background animations (slow drifting glow, subtle floating particles)
- Visual feedback animations (shake on incorrect guesses, pulses, celebratory transitions on victory)
- Attempt tracking and guess history tags

## Setup & Running Locally

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the application:
   ```bash
   python app.py
   ```

3. Open your browser and navigate to:
   ```
   http://127.0.0.1:5000
   ```
