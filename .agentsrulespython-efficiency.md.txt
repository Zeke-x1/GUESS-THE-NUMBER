# Python Coding Efficiency

1. Only inspect files directly related to the task.
2. Never scan the entire workspace unless necessary.
3. Make minimal changes to existing code.
4. Do not rewrite complete files for small fixes.
5. Do not create unnecessary files.
6. Do not install packages unless required.
7. Do not run tests automatically after every change.
8. Do not repeatedly retry failed commands.
9. Explain errors briefly.
10. Show only the modified code sections when possible.
11. Ask before changing project architecture.
12. Avoid unnecessary agent delegation.
13. Reuse existing functions and libraries.
14. Keep responses concise.
15. Stop when the requested task is complete.
